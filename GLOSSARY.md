# SwimTunes

SwimTunes helps a swimmer put selected audio on filesystem-mounted headphones without managing conversion and copying by hand.

## Language

**Source Item**:
One YouTube video or SoundCloud track selected as audio input. It may contain more than one song, or no music at all.
_Avoid_: Song

**Source Playlist**:
A collection of Source Items published on YouTube or SoundCloud; selecting its link does not select every item for download.
_Avoid_: Album, download batch

**Audio File**:
An MP3 produced from a Source Item. Having an Audio File locally does not mean it reached the headphones.
_Avoid_: Downloaded song

**Headphones Device**:
The swimmer's headphones when they appear as a filesystem-mounted removable storage device.
_Avoid_: USB drive

**Headphones Folder**:
The selected destination directory on the Headphones Device where playable Audio Files belong.
_Avoid_: Downloads folder

**Local Library**:
An optional user-selected directory on the computer where Audio Files are retained independently of the Headphones Device.
_Avoid_: Headphones Folder, cache

**Transfer**:
The copying of a complete Audio File to the Headphones Folder. A successful download alone is not a successful Transfer.
_Avoid_: Sync, move
